## Типы спряжения

В обсуждении структуры личного справочника глаголов были введены такие обозначения:

- **1** — первое спряжение (окончание **-ar**): *hablar* — говорить, *apagar* — выключать, *llegar* — приходить, приезжать, *llevar* — носить; брать с собой, *quedar(se)* — оставаться, *tardar* — занимать (о времени), *lograr* — добиться
- **2** — второе спряжение (**-er**): *comer* — есть, *esconder(se)* — прятать(ся)
- **3** — третье спряжение (**-ir**): *vivir* — жить, *abrir* — открывать
- **❗** — неправильный глагол: *ser, estar, ir, tener, venir, hacer, decir, poner, ver, poder, encender, morir, volver, querer, traer, salir*

## Что указывать для каждого глагола

Для **правильных** глаголов достаточно трёх строк — тип, перевод, Participio и один пример:

```
hablar         1    говорить
Participio: hablado
Пример: Hablo un poco de español.
```

Для **неправильных** добавляется строка с формами Presente:

```
hacer          ❗   делать
Presente: hago, haces, hace, hacemos, hacéis, hacen
Participio: hecho
Пример: ¿Qué haces?
```

## Формы Presente неправильных глаголов (из разговора)

- **ser** → soy, eres, es, somos, sois, son — Participio: sido
- **estar** → estoy, estás, está, estamos, estáis, están — estado
- **ir** → voy, vas, va, vamos, vais, van — ido
- **tener** → **tengo**, tienes, tiene, tenemos, tenéis, tienen — tenido
- **venir** → **vengo**, **vienes**, **viene**, venimos, venís, **vienen** — venido
- **hacer** → **hago**, haces, hace, hacemos, hacéis, hacen — hecho (прошедшее: hice)
- **decir** → digo, dices, dice, decimos, decís, dicen — dicho
- **poder** → **puedo**, **puedes**, **puede**, podemos, podéis, **pueden** — podido
- **encender** → enciendo, enciendes, enciende, encendemos, encendéis, encienden — encendido
- **irse** → me voy, te vas, se va, nos vamos, os vais, se van — ido

Полезный приём: выделять жирным **только неправильные формы**, чтобы глаз сразу цеплялся за то, что нужно запомнить.

## Неправильное только причастие

Некоторые глаголы спрягаются обычно, но имеют особое Participio:

- **abrir** → abierto
- **escribir** → escrito
- **poner** → puesto
- **ver** → visto
- **morir** → muerto
- **volver** → vuelto

## Возвратные формы

Возвратные глаголы помечаются так: `quedar(se)`, `esconder(se)`, `irse`.
