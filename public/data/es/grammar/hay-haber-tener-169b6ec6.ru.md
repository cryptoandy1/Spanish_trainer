## Две «жизни» глагола haber

### 1. Безличный haber — только форма **hay**

Значит: есть, имеется, существует. Форма не меняется, о чём бы ни шла речь:

- **Hay un coche.** — Есть машина.
- **Hay dos coches.** — Есть две машины.
- **Hay un problema.** — Есть проблема.
- **Hay muchas personas.** — Есть много людей.
- **Hay un banco cerca.** — Рядом есть банк.
- **Hay mucha gente.** — Здесь много людей.
- **No hay agua.** — Нет воды.
- **¿Hay un baño?** — Здесь есть туалет?

В отрицании чаще говорят без артикля: **No hay banco aquí** (вариант *No hay un banco aquí* подчёркивает «нет какого-то одного банка»).

### 2. Вспомогательный haber (для Pretérito Perfecto)

| Лицо | Форма |
|------|--------|
| yo | he |
| tú | has |
| él | ha |
| nosotros | hemos |
| vosotros | habéis |
| ellos | han |

- **He comido.** — Я поел.
- **¿Has visto la película?** — Ты видел фильм?
- **Han llegado.** — Они приехали.

## Владение — это tener, а не haber

- **¿Tiene un coche?** / **¿Tiene coche?** — У него есть машина?
- **Tengo un coche.** — У меня есть машина.
- **¿Tienes hermanos?** — У тебя есть братья или сёстры?
- **Tiene mucho dinero.** — У него много денег.
- **Tenemos tiempo.** — У нас есть время.

## Главное различие

| Испанский | Значение |
|-----------|----------|
| **Hay un coche en la calle.** | На улице есть машина (существует, находится) |
| **Juan tiene un coche.** | У Хуана есть машина (он владеет) |

Сравни также:
- **Está el banco aquí.** — банк находится здесь (конкретный банк).
- **Hay un banco aquí.** — здесь есть банк (сообщаем о существовании).
- **¿Hay un médico aquí?** / **Mi hermano es médico.** / **Mi hermano tiene un coche.**
