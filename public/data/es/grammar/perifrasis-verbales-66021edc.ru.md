# Perífrasis verbales: глагол + инфинитив и герундий

Конструкции из «вспомогательного» глагола и инфинитива или герундия — их много, и на них держится огромная часть живой речи.

## Сначала важная ловушка

**Continuar и seguir идут с герундием, а не с инфинитивом:**

- ✅ **continuar leyendo** — «продолжать читать»
- ❌ ~~continuar leer~~
- **Sigue lloviendo.** — «Всё ещё идёт дождь.»

## Без предлога: глагол + инфинитив

poder, querer, deber, saber, **soler**, necesitar, esperar, pensar, decidir, intentar, lograr, conseguir, preferir, evitar, prometer

> **Suelo levantarme temprano.** — Обычно я встаю рано. (soler — очень полезный, в русском прямого аналога нет)
>
> **Pienso ir a España.** — Собираюсь поехать в Испанию.

## С предлогом A

| | |
|---|---|
| ir a + inf | ближайшее будущее: **Voy a llamarte** |
| empezar / comenzar a | начинать |
| ponerse a | взяться, приняться (внезапно) |
| volver a | сделать снова: **Volví a intentarlo** |
| llegar a | дойти до того, что |
| aprender a / enseñar a / ayudar a | учиться / учить / помогать |
| atreverse a | осмелиться |
| negarse a | отказаться |

## С предлогом DE

| | |
|---|---|
| acabar de | только что: **Acabo de llegar** — «я только что приехал» |
| dejar de | перестать: **Dejé de fumar** |
| tratar de | пытаться |
| terminar de | закончить делать |
| olvidarse de / acordarse de | забыть / вспомнить |
| tener ganas de | хотеть, «есть желание» |
| estar a punto de | быть на грани, вот-вот |

## С QUE

- **tener que + inf** — «должен»: Tengo que irme
- **hay que + inf** — безлично «надо»: Hay que esperar

## Только с герундием

estar, seguir, continuar, llevar, ir, andar, venir

> **Llevo dos meses estudiando.** — Я учусь уже два месяца. (та же логика, что Llevo dos meses aquí)
>
> **Voy entendiendo.** — Я потихоньку начинаю понимать.

## Must-have для разговора

**acabar de, volver a, dejar de, soler, estar a punto de, llevar + gerundio**
