Время законченных разовых действий: «он пришёл», «она сказала», «он выжил». В книгах на нём держится весь сюжет.

## Правильные глаголы

Отрезаешь *-ar / -er / -ir* и ставишь окончание. У *-er* и *-ir* окончания одинаковые.

| | -ar (*hablar*) | -er / -ir (*vivir*) |
|---|---|---|
| yo | habl**é** | viv**í** |
| tú | habl**aste** | viv**iste** |
| él/ella | habl**ó** | viv**ió** |
| nosotros | habl**amos** | viv**imos** |
| vosotros | habl**asteis** | viv**isteis** |
| ellos | habl**aron** | viv**ieron** |

Ударение в *-é, -ó, -í, -ió* обязательно: *hablo* — «я говорю», *habló* — «он сказал»; *sobrevivo* — «я выживаю», *sobrevivió* — «он выжил».

## Неправильные, которые будут на каждой странице

- *ser* и *ir* совпадают: fui, fuiste, **fue**, fuimos, fueron. «Был» или «пошёл» — по смыслу.
- Группа со своей основой и окончаниями **без ударения** (-e, -iste, -o, -imos, -ieron):
  *tener* → **tuvo**, *estar* → **estuvo**, *hacer* → **hizo**, *poder* → **pudo**, *poner* → **puso**,
  *saber* → **supo**, *querer* → **quiso**, *venir* → **vino**, *decir* → **dijo** (во множественном *dijeron*, без *i*).
- *dar* → **dio**, *ver* → **vio** (vi, viste, vio… — без тильды, потому что слова односложные).

## Мелкие подлянки

- Глаголы на *-ir* с чередованием в корне в 3-м лице меняют *e→i* и *o→u*: *pedir* → **pidió**, *dormir* → **durmió**, *morir* → **murió**, *sugerir* → **sugirieron**.
- Гласная перед окончанием — *i* становится *y*: *leer* → **leyó**, *oír* → **oyó**, *caer* → **cayó**.
- В форме *yo* меняется написание, чтобы сохранить звук: *buscar* → bus**qué**, *llegar* → lle**gué**, *negar* → ne**gué**, *empezar* → empe**cé**, *comenzar* → comen**cé**.
- Чередование настоящего времени сюда не переходит: *pienso*, но *pensé, pensó*.

## Рядом всегда imperfecto

Indefinido двигает сюжет («вдруг кто-то постучал»), imperfecto (*hablaba, vivía, era*) рисует фон. Сравни: *vio* — «увидел» один раз, *veía* — «видел» постоянно; *fabricó* — «произвела» один раз, *fabricaba* — «производила» вообще.
