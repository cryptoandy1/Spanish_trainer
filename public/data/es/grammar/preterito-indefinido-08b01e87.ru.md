Время законченных разовых действий: «он пришёл», «она сказала», «он выжил». Событие с началом и концом, «бац — случилось». В книгах на нём держится весь сюжет.

## Правильные глаголы

Отрезаешь *-ar / -er / -ir* и ставишь окончание. У *-er* и *-ir* окончания одинаковые.

| | -ar (*hablar*) | -er / -ir (*vivir*) |
|---|---|---|
| yo | habl**é** | viv**í** |
| tú | habl**aste** | viv**iste** |
| él/ella | habl**ó** | viv**ió** |
| nosotros | habl**amos** | viv**imos** |
| vosotros | habl**asteis** | viv**isteis** |
| ellos | habl**aron** | viv**ieron** |

Ударение в *-é, -ó, -í, -ió* обязательно: *hablo* — «я говорю», *habló* — «он сказал»; *sobrevivo* — «я выживаю», *sobrevivió* — «он выжил».

## Неправильные глаголы: полный список

Неправильных на самом деле немного. Они делятся на четыре группы, и внутри группы всё работает одинаково. Других сюрпризов в indefinido нет.

### 1. Совсем дикие — учить наизусть

| | *ser / ir* | *dar* | *ver* |
|---|---|---|---|
| yo | fui | di | vi |
| tú | fuiste | diste | viste |
| él/ella | **fue** | **dio** | **vio** |
| nosotros | fuimos | dimos | vimos |
| vosotros | fuisteis | disteis | visteis |
| ellos | fueron | dieron | vieron |

- *ser* и *ir* в indefinido совпадают полностью. «Был» или «пошёл» — понимаешь по смыслу.
- *dar* — глагол на *-ar*, но берёт окончания *-er/-ir*.
- *fui, fue, di, dio, vi, vio* пишутся без тильды: слова односложные.

### 2. «Сильные» претериты: новая основа и окончания без ударения

У всех глаголов этой группы одни и те же окончания, **без ударения**: **-e, -iste, -o, -imos, -isteis, -ieron**.

| Глагол | Основа | yo | él/ella | ellos |
|---|---|---|---|---|
| *tener* | tuv- | tuve | tuvo | tuvieron |
| *estar* | estuv- | estuve | estuvo | estuvieron |
| *andar* | anduv- | anduve | anduvo | anduvieron |
| *poder* | pud- | pude | pudo | pudieron |
| *poner* | pus- | puse | puso | pusieron |
| *saber* | sup- | supe | supo | supieron |
| *caber* | cup- | cupe | cupo | cupieron |
| *haber* | hub- | hube | **hubo** | hubieron |
| *querer* | quis- | quise | quiso | quisieron |
| *venir* | vin- | vine | vino | vinieron |
| *hacer* | hic- | hice | **hizo** | hicieron |
| *decir* | dij- | dije | dijo | **dijeron** |
| *traer* | traj- | traje | trajo | **trajeron** |
| *conducir* | conduj- | conduje | condujo | **condujeron** |

Целиком, на примере *tener*: tuve, tuviste, tuvo, tuvimos, tuvisteis, tuvieron.

- Ударения нет: *tuve, tuvo*, а не «tuvé, tuvó». Сравни с правильными *hablé, habló*.
- *hacer* → **hizo** с *z* в 3-м лице единственного числа, чтобы сохранить звук.
- У основ на **j** (*dij-, traj-, -duj-*) в 3-м лице множественного числа окончание **-eron**, без *i*: *dijeron, trajeron, condujeron*.
- **hubo** — «было, имелось»: прошедшее от *hay*.
- Все глаголы на **-ducir** идут по образцу *conducir*: *traducir* → traduje, *producir* → produje.

Производные спрягаются так же, как основной глагол:

| Основа | Производные |
|---|---|
| *tener* → tuv- | *mantener* → mantuve, *obtener* → obtuve, *contener* → contuve |
| *poner* → pus- | *suponer* → supuse, *componer* → compuse |
| *venir* → vin- | *prevenir* → previne |
| *hacer* → hic- | *deshacer* → deshice |
| *traer* → traj- | *atraer* → atraje, *distraer* → distraje |
| *decir* → dij- | *predecir* → predije |

### 3. Глаголы на -ir с чередованием — только в 3-м лице

Меняется только *él/ella* и *ellos*. Остальные формы обычные: *pedí, pediste, pedimos, pedisteis*.

- **e → i**: *pedir* → **pidió, pidieron**; *servir* → sirvió; *seguir* → siguió; *sentir* → sintió; *preferir* → prefirió; *mentir* → mintió; *repetir* → repitió; *vestir* → vistió; *divertirse* → se divirtió; *sugerir* → sugirieron; *reír* → **rio, rieron**; *sonreír* → sonrió, sonrieron.
- **o → u**: *dormir* → **durmió, durmieron**; *morir* → **murió, murieron**.

*rio* по нормам 2010 года пишется без тильды, потому что считается односложным. Старое написание *rió* до сих пор встречается часто.

Чередование настоящего времени у глаголов на *-ar* и *-er* сюда не переходит: *pienso*, но *pensé, pensó*.

### 4. Меняется только написание

Это даже не неправильные глаголы: буква меняется, чтобы не поехал звук.

- **-car → -qué** в форме *yo*: *buscar* → bus**qué**, *tocar* → to**qué**, *sacar* → sa**qué**.
- **-gar → -gué**: *llegar* → lle**gué**, *pagar* → pa**gué**, *jugar* → ju**gué**, *negar* → ne**gué**.
- **-zar → -cé**: *empezar* → empe**cé**, *comenzar* → comen**cé**, *cruzar* → cru**cé**.
- **-guar → -güé**: *averiguar* → averi**güé**.
- **i → y** между гласными в 3-м лице: *leer* → **leyó, leyeron**; *creer* → creyó; *oír* → oyó; *caer* → cayó; *construir* → construyó; *huir* → huyó.

В первых четырёх случаях меняется только *yo*: *busqué*, но *buscaste, buscó*.

### Как это учить

Вызубри группу 2 (около 14 основ) и ser/ir, dar, ver — это 90 % всех трудностей. Группы 3 и 4 работают по правилу.

## Рядом всегда imperfecto

Indefinido двигает сюжет («вдруг кто-то постучал»), imperfecto (*hablaba, vivía, era*) рисует фон. Сравни: *vio* — «увидел» один раз, *veía* — «видел» постоянно; *fabricó* — «произвела» один раз, *fabricaba* — «производила» вообще.

- *Llovía cuando salí de casa.* — Шёл дождь (фон), когда я вышел из дома (событие).
- *Todo iba bien hasta que dejaron de dar permisos de residencia.* — Всё было хорошо, пока они не перестали выдавать ВНЖ: фон, который оборвало событие.
- *Las casas fueron pintadas de azul.* — Дома покрасили в синий (кто-то это сделал), а *estaban pintadas* — какими они были.

Для сегодняшнего дня в Испании берут pretérito perfecto: *Hoy he visto a Juan*. Для вчера и раньше — indefinido: *Ayer vi a Juan*.
