# Этот / эта / эти

## Ближнее (рядом со мной)

| Русский | Испанский |
|--------|----------|
| этот | **este** |
| эта | **esta** |
| эти (муж.) | **estos** |
| эти (жен.) | **estas** |

Примеры: **Este libro** — эта книга (муж. род), **Esta casa** — этот дом (жен. род → casa), **Estos chicos** — эти парни, **Estas chicas** — эти девушки.

## Чуть дальше (тот / та / те)

| Русский | Испанский |
|--------|----------|
| тот | **ese** |
| та | **esa** |
| те (муж.) | **esos** |
| те (жен.) | **esas** |

Примеры: **Ese coche** — та машина, **Esa persona** — тот человек, **Esos libros** — те книги, **Esas casas** — те дома.

## Логика
- **este / esta** — ближе ко мне
- **ese / esa** — ближе к тебе / дальше
- **aquel / aquella** — совсем далеко

## Окончания
- **-e → este / ese** (мужской)
- **-a → esta / esa** (женский)
- **-os → estos / esos** (мн. муж.)
- **-as → estas / esas** (мн. жен.)

## Пример в предложении
«Тот дом — дом моего друга»:

👉 **Esa casa es la casa de mi amigo.**

Более естественно (без повтора *casa*): **Esa es la casa de mi amigo.**
