# Hace + время: как сказать «…назад»

**hace + количество времени** = «столько-то времени назад»:

> **Llegué aquí hace dos meses.** — Я приехал сюда два месяца назад.

Разбор:

- **llegué** — «я приехал / прибыл» (pretérito indefinido от llegar)
- **aquí** — «сюда / здесь»
- **hace dos meses** — «два месяца назад»

Два правила:

1. Порядок именно **hace + количество**, а не наоборот.
2. **Hace не меняется** — всегда 3-е лицо единственного числа, хоть про дни, хоть про годы.

## Варианты той же мысли

| Фраза | Что значит |
|---|---|
| Vine aquí hace dos meses | venir вместо llegar — тоже нормально |
| Hace dos meses que llegué aquí | то же самое, но с que; оба порядка рабочие |
| Me mudé aquí hace dos meses | «я переехал сюда…» — если речь о переезде |
| **Llevo dos meses aquí** | «я здесь уже два месяца» — не момент приезда, а длительность пребывания; очень испанская конструкция |

## Готовый набор с hace

- **hace un rato** — недавно, только что
- **hace poco** — недавно
- **hace unos días** — несколько дней назад
- **hace mucho (tiempo)** — давно
- **hace años** — много лет назад

## Не путай три «hace»

| | |
|---|---|
| **hace calor** | «жарко» — погода |
| **hace dos meses** | «два месяца назад» |
| **él hace** | «он делает» — глагол hacer |

Одно слово, три работы. Контекст разруливает.
