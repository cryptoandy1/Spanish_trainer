## Сколько неправильных глаголов в испанском

Точного числа нет — всё зависит от того, что считать «неправильным».

1. **Полностью неправильные глаголы** — около **20–30**: ser, ir, haber, estar, dar, saber, ver, caber.
2. **Глаголы с изменением корня (stem-changing)** — несколько сотен:
   - pensar → **pienso**
   - poder → **puedo**
   - pedir → **pido**
   - dormir → **duermo**
3. **Глаголы с орфографическими изменениями** — несколько десятков (меняют букву ради сохранения произношения):
   - pagar → pagué
   - buscar → busqué
   - empezar → empecé
4. **Глаголы с неправильными формами только в отдельных временах**: tener, venir, poner, salir, hacer, decir, traer.

Для свободной речи достаточно хорошо знать примерно **70–100 самых употребительных** неправильных глаголов. Для сравнения: в английском обычно говорят о 180–200 неправильных глаголах, но в испанском система спряжения богаче — один и тот же глагол может быть правильным в одном времени и неправильным в другом.

## План изучения (по группам, а не по алфавиту)

**I. Полностью неправильные:** ser, estar, ir, haber.

**II. Глаголы на -go:** tener, venir, poner, salir, hacer, decir, oír.

**III. Изменение корня:** e → ie, o → ue, e → i, u → ue.

**IV. Неправильный Pretérito Indefinido.**

**V. Неправильное будущее и условное.**

## Группа -go: единый шаблон

Сравни tener и venir:

| Tener | Venir |
|--------|--------|
| tengo | vengo |
| tienes | vienes |
| tiene | viene |
| tenemos | venimos |
| tenéis | venís |
| tienen | vienen |

Модель одна и та же:
- **yo → -go**
- **tú / él / ellos → e → ie**
- **nosotros / vosotros** — без изменения корня.

У poner, salir, hacer изменения корня нет — неправильна только форма **yo**: pongo, salgo, hago.

## Полезные выражения с этими глаголами

- **ir a + инфинитив** — близкое будущее: Voy a estudiar. / Vamos a comer. / Va a llover.
- a + el = **al**: Voy **al** supermercado, Viene **al** trabajo (но: Vamos **a casa**, без артикля).
- **hacer** в разговоре о погоде: Hace frío. Hace calor. Hace viento. Hace sol. Hace buen tiempo.
