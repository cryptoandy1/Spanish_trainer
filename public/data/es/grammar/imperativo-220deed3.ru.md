## 1. Tú (ты)

Берётся форма 3-го лица ед. числа Presente **без -s**:

- **-AR:** hablar → **habla**, girar → **gira**
- **-ER:** comer → **come**, beber → **bebe**
- **-IR:** vivir → **vive**, abrir → **abre**

Примеры:
- **Gira a la derecha.** — Поверни направо.
- **Sigue recto.** — Езжай прямо.
- **Para aquí.** — Остановись здесь.

## 2. Usted (вежливое «Вы»)

Берётся форма **Presente de subjuntivo**:

- **-AR** → окончание **-e**: hablar → que yo **hable** → **hable**; girar → que yo **gire** → **gire**
- **-ER / -IR** → окончание **-a**: comer → que yo **coma** → **coma**; vivir → que yo **viva** → **viva**

Примеры:
- **Gire a la derecha.** — Поверните направо.
- **Siga recto.** — Следуйте прямо.
- **Pare aquí.** — Остановитесь здесь.

## 3. Vosotros (вы, неформально, Испания)

Инфинитив, **-r → -d**:

- hablar → **hablad**, girar → **girad**, comer → **comed**, vivir → **vivid**

Примеры:
- **Girad a la izquierda.** — Поверните налево.
- **Venid aquí.** — Идите сюда.

## 4. Ustedes (вы, формально / мн. число)

Та же форма, что у usted, во множественном числе:

- hablar → **hablen**, girar → **giren**, comer → **coman**, vivir → **vivan**

Примеры:
- **Sigan recto.** — Езжайте прямо.
- **Giren a la derecha.** — Поверните направо.

## 5. Nosotros («давайте ...»)

Тоже из Presente de subjuntivo:

- **-AR → -emos:** hablar → **hablemos**, girar → **giremos**
- **-ER / -IR → -amos:** comer → **comamos**, vivir → **vivamos**, seguir → **sigamos**

Примеры:
- **Sigamos recto.** — Давайте продолжим прямо.
- **Giremos a la derecha.** — Давайте повернём направо.
- **Paremos aquí.** — Давайте остановимся здесь.
- **Vamos a casa.** — Давайте пойдём домой. (у **ir** неправильная форма **vamos**)

Важно: с таксистом nosotros не используется — ✅ **Gire a la derecha**, ❌ **Giremos a la derecha**.

## Неправильные формы для tú

| Infinitivo | Tú |
|---|---|
| decir | di |
| hacer | haz |
| ir | ve |
| poner | pon |
| salir | sal |
| ser | sé |
| tener | ten |
| venir | ven |

Примеры: **Ven aquí.** — Иди сюда. **Haz esto.** — Сделай это. **Pon el libro aquí.** — Положи книгу сюда.

## Сводная таблица (такси)

| Лицо | seguir | girar | parar |
|---|---|---|---|
| tú | sigue | gira | para |
| usted | siga | gire | pare |
| nosotros | sigamos | giremos | paremos |
| vosotros | seguid | girad | parad |
| ustedes | sigan | giren | paren |

В Испании к незнакомому водителю обращаются на **usted**: **Siga recto**, **Gire a la derecha**, **Pare aquí**, **Espere un momento**.
