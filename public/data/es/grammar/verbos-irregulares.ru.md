# Неправильные глаголы: как устроена система

Сводная тема. Материал собран из твоих разговоров про неправильные глаголы и
сверен с таблицами спряжения в разделе **Глаголы** — все примеры ниже взяты из
глаголов, которые уже есть в твоём справочнике.

## 1. «Неправильный» — это не одно явление, а четыре

Точного числа неправильных глаголов нет: всё зависит от того, что считать
неправильным. Полезнее делить их на типы — внутри типа глаголы ведут себя
одинаково, и учить их надо группой, а не по алфавиту.

| Тип | Что происходит | Сколько таких в твоём справочнике |
|---|---|---|
| Полностью неправильные | Формы не выводятся из инфинитива | 25 |
| Изменение корня (stem-changing) | Гласная в корне меняется под ударением | 16 |
| Орфографические | Буква меняется ради сохранения звука | 5 |
| Правильные | Ничего не меняется | 31 |

Для свободной речи достаточно уверенно знать примерно **70–100 самых частых**
неправильных глаголов. Для сравнения: в английском обычно называют 180–200
неправильных глаголов, но в испанском система спряжения богаче — один и тот же
глагол может быть правильным в одном времени и неправильным в другом.

## 2. Полностью неправильные

Ядро, которое надо просто знать наизусть — это самые частотные глаголы языка:

**ser → soy**, **estar → estoy**, **ir → voy**, **haber → he**, **dar → doy**,
**saber → sé**, **ver → veo**, **querer → quiero**, **poder → puedo**.

## 3. Группа -go: один шаблон на много глаголов

Большая группа, где неправильна **только форма yo** — она оканчивается на **-go**:

**decir → digo**, **hacer → hago**, **oír → oigo**, **poner → pongo**,
**salir → salgo**, **tener → tengo**, **traer → traigo**, **valer → valgo**,
**venir → vengo**.

Сравни tener и venir — модель одна и та же:

| Лицо | tener | venir |
|---|---|---|
| yo | tengo | vengo |
| tú | tienes | vienes |
| él / ella / usted | tiene | viene |
| nosotros | tenemos | venimos |
| vosotros | tenéis | venís |
| ellos / ustedes | tienen | vienen |

Правило внутри группы:

- **yo → -go**
- **tú / él / ellos → e → ie** (tienes, viene, vienen)
- **nosotros / vosotros** — корень **не** меняется

У poner, salir, hacer изменения корня нет вообще — неправильна только форма yo:
**pongo**, **salgo**, **hago**.

## 4. Изменение корня (stem-changing)

Гласная корня меняется во всех лицах, **кроме nosotros и vosotros** — там корень
всегда остаётся как в инфинитиве. Это и есть главный опознавательный признак.

### O → UE

**acostarse → me acuesto**, **aprobar → apruebo**, **dormir → duermo**,
**encontrar → encuentro**, **morir → muero**, **poder → puedo**, **volver → vuelvo**

### E → IE

**cerrar → cierro**, **despertarse → me despierto**, **empezar → empiezo**,
**encender → enciendo**, **pensar → pienso**, **querer → quiero**, **sentarse → me siento**

### E → I

**pedir → pido**, **seguir → sigo**, **servir → sirvo**, **vestirse → me visto**

Проверка на nosotros:

- me acuesto → **nos acostamos** (не «nos acuestamos»)
- me visto → **nos vestimos**
- me siento → **nos sentamos**

## 5. Орфографические изменения

Глагол правильный на слух, но букву приходится менять, чтобы согласный звучал
так же:

- **buscar → busqué** (c → qu перед e)
- **llegar → llegué**, **apagar → apagué** (g → gu перед e)
- **empezar → empecé** (z → c перед e)
- **conocer → conozco**, **parecer → parezco** (c → zc перед o)

## 6. План изучения — по группам, а не по алфавиту

1. **Полностью неправильные:** ser, estar, ir, haber.
2. **Группа -go:** tener, venir, poner, salir, hacer, decir, oír.
3. **Изменение корня:** e → ie, o → ue, e → i, u → ue.
4. **Неправильный pretérito indefinido.**
5. **Неправильные futuro и condicional.**

## 7. Полезные конструкции с этими глаголами

- **ir a + инфинитив** — ближайшее будущее: Voy a estudiar. Vamos a comer. Va a llover.
- **a + el = al**: Voy **al** supermercado. Viene **al** trabajo. Но: Vamos **a casa** — без артикля.
- **hacer** о погоде: Hace frío. Hace calor. Hace viento. Hace sol. Hace buen tiempo.
