# Presente (настоящее время)

Presente используется, когда действие происходит **сейчас**, **обычно**, **регулярно**, **всегда**.

- **Vivo en Berlín.** — Я живу в Берлине.
- **Hablo español.** — Я говорю по-испански.
- **Como pizza.** — Я ем пиццу.

## Три типа глаголов

- **-AR** → hablar (говорить)
- **-ER** → comer (есть)
- **-IR** → vivir (жить)

## HABLAR

| Лицо | Форма |
|------|------|
| yo | hablo |
| tú | hablas |
| él/ella/usted | habla |
| nosotros | hablamos |
| vosotros | habláis |
| ellos/ustedes | hablan |

- **Hablo español.** — Я говорю по-испански.
- **Hablamos mucho.** — Мы много говорим.
- **¿Hablas inglés?** — Ты говоришь по-английски?

## COMER

| Лицо | Форма |
|------|------|
| yo | como |
| tú | comes |
| él/ella/usted | come |
| nosotros | comemos |
| vosotros | coméis |
| ellos/ustedes | comen |

- **Como pizza.** — Я ем пиццу.
- **Comemos juntos.** — Мы едим вместе.
- **¿Comes carne?** — Ты ешь мясо?

## VIVIR

| Лицо | Форма |
|------|------|
| yo | vivo |
| tú | vives |
| él/ella/usted | vive |
| nosotros | vivimos |
| vosotros | vivís |
| ellos/ustedes | viven |

- **Vivo en España.** — Я живу в Испании.
- **Vivimos aquí.** — Мы живём здесь.
- **¿Vives solo?** — Ты живёшь один?

## Окончания (главный паттерн)

- **-AR**: o / as / a / amos / áis / an
- **-ER**: o / es / e / emos / éis / en
- **-IR**: o / es / e / imos / ís / en

Правило простое: убираем окончание инфинитива и добавляем новое — hablar → habl + o / as / a…, comer → com + o / es / e…, vivir → viv + o / es / e…
