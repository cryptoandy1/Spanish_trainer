# Местоимения в испанском (только Presente)

## 1. Личные местоимения (подлежащее)

| Русский | Испанский |
|---|---|
| я | yo |
| ты | tú |
| он | él |
| она | ella |
| Вы | usted |
| мы | nosotros / nosotras |
| вы | vosotros / vosotras |
| они (м.) | ellos |
| они (ж.) | ellas |
| Вы (мн.) | ustedes |

Обычно их **опускают**, потому что окончание глагола уже показывает лицо:

- **Yo hablo español.** = **Hablo español.**
- **Tú comes mucho.** = **Comes mucho.**

Местоимение используют для акцента/противопоставления: **Yo estudio. Tú trabajas.**

## 2. Прямое дополнение (кого? что?)

| Русский | Испанский |
|---|---|
| меня | me |
| тебя | te |
| его | lo |
| её | la |
| нас | nos |
| вас | os |
| их (м.) | los |
| их (ж.) | las |

Стоят **перед спрягаемым глаголом**:

- Me conoce. — Он меня знает.
- Te veo. — Я тебя вижу.
- La compro. — Я её покупаю.
- Lo entiendo. — Я это понимаю.

Замена существительного:

- Veo a Juan. → Lo veo.
- Compro el coche. → Lo compro.
- Compro la mesa. → La compro.

## 3. Косвенное дополнение (кому? для кого?)

| Русский | Испанский |
|---|---|
| мне | me |
| тебе | te |
| ему | le |
| ей | le |
| нам | nos |
| вам | os |
| им | les |

- Doy dinero a Ana. → **Le doy dinero.** — Я даю ей деньги.
- Escribo a mi madre. → **Le escribo.** — Я пишу ей.
- Compramos un regalo para ellos. → **Les compramos un regalo.**

## 4. Два местоимения вместе

Порядок всегда: **КОСВЕННОЕ + ПРЯМОЕ + глагол**

- Me lo da. — Он мне это даёт.
- Te la compro. — Я покупаю её тебе.
- Nos los enseñan. — Они показывают их нам.

**Важное правило:** если подряд получаются *le lo* / *les lo*, то **le → se**:

- ✅ Se lo doy. — Я даю это ему.
- ❌ Le lo doy.

Ещё: Se la compro. Se los damos. Se las vende.

## 5. Возвратные местоимения

me / te / se / nos / os / se — используются с возвратными глаголами (например, *levantarse*):

- Me levanto. — Я встаю.
- Te llamas Pedro. — Тебя зовут Педро.
- Se ducha. — Он принимает душ.
- Nos acostamos. — Мы ложимся спать.

## 6. Притяжательные местоимения-прилагательные (перед существительным)

mi, tu, su, su, su, nuestro, vuestro, su

- Mi coche. Tu casa. Su hermano. Nuestro perro.
- Мн. число: mis, tus, sus, nuestros

## 7. Самостоятельные притяжательные

mío, tuyo, suyo, nuestro, vuestro — когда существительное уже известно:

- Este coche es mío. — Эта машина моя.
- La casa es nuestra. El libro es suyo. ¿Es tuyo?

## 8. Указательные

este, esta, esto, estos, estas — этот/эта/это/эти; **ese** — тот (около собеседника); **aquel** — вон тот (далеко).

- Este coche. Ese libro. Aquella casa.

## 9. Неопределённые

algo — что-то, nada — ничего, alguien — кто-то, nadie — никто, todo — всё, todos — все, mucho — много, poco — мало, otro — другой.

- No veo nada. Hay alguien. Todo está bien.

## 10. Вопросительные

qué — что, quién — кто, cuál — какой, cuánto — сколько.

- ¿Qué haces? ¿Quién viene? ¿Cuánto cuesta?

## 11. Относительные

que — который, quien — который (о людях), donde — где.

- La chica que trabaja aquí. El hombre que habla español.

## 12. Безличное «se»

- Se vende. — Продаётся.
- Se habla español. — Здесь говорят по-испански.
- Se vive bien aquí. — Здесь хорошо живётся.

## Позиция местоимений в Presente

Перед спрягаемым глаголом: Me llamo Ana. Lo compro. Le escribo. Se ducha.

Если два местоимения: Me lo da. Te la compra. Se los vende.

Схема: **Подлежащее (Yo) + местоимение (me/te/lo/la/le/se/nos) + глагол (hablo/veo/compro/escribo)** → Yo lo compro.

## Частая трудность: глаголы с изменением корня

- **O → UE:** dormir → duermo, volver → vuelvo, acostar → acuesto, poder → puedo
- **E → IE:** querer → quiero, cerrar → cierro, pensar → pienso, sentarse → me siento, despertar → despierto
- **E → I:** vestir → visto, pedir → pido, servir → sirvo

Формы **nosotros** и **vosotros** корень обычно **не меняют**: me acuesto → nos acostamos; me visto → nos vestimos; me siento → nos sentamos.
