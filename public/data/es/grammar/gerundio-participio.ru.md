# Герундий и причастие

Обе формы образуются от глагола, но выполняют разные функции.

## Герундий (gerundio)

Образование: **-ar** → **-ando**, **-er/-ir** → **-iendo**.

- hablar → hablando
- comer → comiendo
- vivir → viviendo

Герундий описывает действие **в процессе** и почти всегда используется с **estar** (прогрессивные времена):

- *Estoy hablando por teléfono.* — Я разговариваю по телефону (прямо сейчас).
- *Estábamos comiendo cuando llamaste.* — Мы ели, когда ты позвонил.

Герундий неизменяем — не согласуется по роду и числу.

### Неправильные герундии

Некоторые глаголы меняют корневую гласную:

| Инфинитив | Герундий |
|---|---|
| decir | diciendo |
| dormir | durmiendo |
| leer | leyendo |
| pedir | pidiendo |

## Причастие (participio)

Образование: **-ar** → **-ado**, **-er/-ir** → **-ido**.

- hablar → hablado
- comer → comido
- vivir → vivido

Причастие используется в двух ролях:

1. **Сложные времена** (haber + participio) — обозначает завершённое действие:
   *He hablado con él.* — Я поговорил с ним.
2. **Как прилагательное** — тогда согласуется по роду и числу:
   *La puerta está cerrada.* — Дверь закрыта (жен. род).

### Неправильные причастия (самые частые)

| Инфинитив | Причастие |
|---|---|
| hacer | hecho |
| decir | dicho |
| escribir | escrito |
| ver | visto |
| poner | puesto |
| volver | vuelto |
| abrir | abierto |
| romper | roto |

## Главное различие

Герундий = *делая* (процесс, наречная функция).
Причастие = *сделанный* (результат, может быть прилагательным).
