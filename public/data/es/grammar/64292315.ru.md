В испанском языке отглагольные прилагательные (*adjetivos verbales*) чаще всего образуются от **причастий прошедшего времени** (*participios*). Многие из них ведут себя как обычные прилагательные: согласуются с существительным в роде и числе.

## Как образуются

Для правильных глаголов:

- **-ar → -ado**: hablar → **hablado**, cerrar → **cerrado**
- **-er / -ir → -ido**: comer → **comido**, vivir → **vivido**

Когда такие формы используются как прилагательные, они изменяются:

- un libro **cerrado** — закрытая книга
- una puerta **cerrada** — закрытая дверь
- unos libros **cerrados**
- unas puertas **cerradas**

## Примеры

- una ventana **abierta** — открытое окно
- un hombre **cansado** — уставший мужчина
- una mujer **cansada** — уставшая женщина
- un vaso **roto** — разбитый стакан
- una silla **rota** — сломанный стул

## Неправильные формы причастий

- abrir → **abierto**
- escribir → **escrito**
- decir → **dicho**
- hacer → **hecho**
- poner → **puesto**
- ver → **visto**
- volver → **vuelto**
- romper → **roto**
- morir → **muerto**

Например:

- la puerta **está abierta** — дверь открыта
- un trabajo **bien hecho** — хорошо сделанная работа
- un libro **escrito** en español — книга, написанная на испанском

## Важное различие

1. **Как часть глагольной формы** (с *haber*) — причастие **не изменяется**:
   - He **comido**.
   - Hemos **escrito** una carta.
2. **Как прилагательное** — **изменяется** по роду и числу:
   - La carta está **escrita**.
   - Las cartas están **escritas**.

## Соответствия русским отглагольным прилагательным

| Русский | Испанский |
|---|---|
| закрытый | cerrado |
| открытый | abierto |
| уставший | cansado |
| сломанный | roto |
| написанный | escrito |
| сделанный | hecho |
| потерянный | perdido |
| забытый | olvidado |

Для уровня A1–A2 достаточно запомнить, что **причастия прошедшего времени очень часто используются как прилагательные** — именно в этой роли они чаще всего встречаются в повседневной речи.
