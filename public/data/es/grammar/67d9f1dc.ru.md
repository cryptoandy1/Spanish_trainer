# Прилагательные: род и число

Прилагательное согласуется с существительным по **роду** и **числу**.

| Мужской род | Женский род |
|-------------|-------------|
| **un chico bonito** — красивый парень | **una chica bonita** — красивая девушка |
| **un perro pequeño** — маленькая собака (кобель) | **una gata pequeña** — маленькая кошка |

Множественное число: **unos chicos bonitos** — красивые парни, **unas chicas bonitas** — красивые девушки.

## 1. Тип на -o
- **-o** → мужской род
- **-a** → женский род
- **-os** → мужской множественный
- **-as** → женский множественный

| Мужской | Женский |
|---------|----------|
| alto (высокий) | alta |
| pequeño | pequeña |
| bueno | buena |
| guapo | guapa |

## 2. Не меняются по роду
Прилагательные на **-e** и на многие согласные меняются только по числу:

- un chico **inteligente** / una chica **inteligente** → chicos/chicas **inteligentes**
- un hombre **interesante** / una mujer **interesante**
- **difícil → difíciles**, **fácil → fáciles**

## 3. Позиция
Обычный порядок — прилагательное **после** существительного:

- **un coche nuevo** — новая машина
- **una casa grande** — большой дом
- **un libro interesante** — интересная книга

## Важное уточнение
Прилагательное согласуется не с тем словом, которое стоит перед ним, а **с существительным, которое оно описывает**:

- **La casa blanca.** — blanca согласуется с *casa*.
- **La casa es blanca.** — хотя blanca стоит после **es**, оно всё равно согласуется с *casa*.
