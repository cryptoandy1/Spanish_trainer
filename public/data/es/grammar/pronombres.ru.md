# Местоимения: полная система

Сводная тема. Собрана из твоих разговоров про местоимения, обращение на
tú / usted и порядок слов; отдельные разборы (te/le/les/os, este/ese,
esto/eso/aquello, безличное se) остались отдельными темами — здесь общая карта.

## 1. Личные местоимения — подлежащее

| Русский | Испанский |
|---|---|
| я | yo |
| ты | tú |
| он | él |
| она | ella |
| Вы (вежливо, к одному) | usted |
| мы | nosotros / nosotras |
| вы (мн., Испания) | vosotros / vosotras |
| они (м.) | ellos |
| они (ж.) | ellas |
| вы (мн., вежливо) | ustedes |

Главное: их обычно **опускают** — окончание глагола уже показывает лицо.

- **Yo hablo español.** = **Hablo español.**
- **Tú comes mucho.** = **Comes mucho.**

Местоимение ставят только для акцента или противопоставления:
**Yo estudio. Tú trabajas.**

**usted** грамматически ведёт себя как «он/она»: usted **es**, usted **tiene**,
usted **habla**. Если сомневаешься, к кому как обращаться — начинай с usted, это
безопасно; в Испании быстро переходят на tú.

## 2. Прямое дополнение — кого? что?

| Русский | Испанский |
|---|---|
| меня | me |
| тебя | te |
| его | lo |
| её | la |
| нас | nos |
| вас | os |
| их (м.) | los |
| их (ж.) | las |

Заменяют существительное и стоят **перед спрягаемым глаголом**:

- Veo a Juan. → **Lo veo.**
- Compro el coche. → **Lo compro.**
- Compro la mesa. → **La compro.**
- Me conoce. — Он меня знает. / Te veo. — Я тебя вижу.

## 3. Косвенное дополнение — кому? для кого?

| Русский | Испанский |
|---|---|
| мне | me |
| тебе | te |
| ему / ей / Вам | le |
| нам | nos |
| вам (мн., Испания) | os |
| им / вам (ustedes) | les |

- Doy dinero a Ana. → **Le doy dinero.**
- Escribo a mi madre. → **Le escribo.**
- Compramos un regalo para ellos. → **Les compramos un regalo.**

Разница te / le / les / os решает, насколько вежливо и к скольким людям ты
обращаешься:

- **Mamá, quiero decirte algo.** — одному человеку, на tú
- **Mamá, papá, quiero deciros algo.** — двоим, vosotros (естественно для Испании)
- **Mamá, papá, quiero decirles algo.** — двоим, ustedes (Латинская Америка)

## 4. Два местоимения подряд

Порядок всегда: **косвенное + прямое + глагол**.

- **Me lo da.** — Он мне это даёт.
- **Te la compro.** — Я покупаю её тебе.
- **Nos los enseñan.** — Они показывают их нам.

**Ключевое правило:** если подряд получается *le lo* / *les lo*, то **le → se**:

- ✅ **Se lo doy.** — Я даю это ему.
- ❌ ~~Le lo doy.~~

Ещё: Se la compro. Se los damos. Se las vende.

## 5. Где ставить местоимение

Перед спрягаемым глаголом: **Me llamo Ana. Lo compro. Le escribo. Se ducha.**

Если после спрягаемого глагола идёт инфинитив — можно **присоединить к
инфинитиву** или поставить **перед** спрягаемым глаголом, смысл одинаковый:

- **Quiero decirles algo.** = **Les quiero decir algo.**
- **Quiero preguntarte algo.** — Я хочу тебя кое о чём спросить.
- **Voy a contarles una historia.** — Я расскажу вам историю.

Общая схема: *подлежащее + местоимение + глагол* → **Yo lo compro.**

## 6. Возвратные

**me / te / se / nos / os / se** — с возвратными глаголами (levantarse, ducharse,
acostarse):

- **Me levanto.** — Я встаю.
- **Te llamas Pedro.** — Тебя зовут Педро.
- **Se ducha.** — Он принимает душ.
- **Nos acostamos.** — Мы ложимся спать.

## 7. Притяжательные

**Перед существительным:** mi, tu, su, nuestro, vuestro, su
(мн. ч.: mis, tus, sus, nuestros).

- Mi coche. Tu casa. Su hermano. Nuestro perro.

**Самостоятельные** — когда существительное уже известно: mío, tuyo, suyo,
nuestro, vuestro.

- **Este coche es mío.** — Эта машина моя.
- La casa es nuestra. El libro es suyo. ¿Es tuyo?

## 8. Указательные

**este / esta / estos / estas** — этот (рядом со мной);
**ese / esa / esos / esas** — тот (около собеседника);
**aquel / aquella** — вон тот (далеко).

- Este coche. Ese libro. Aquella casa.

Средний род — **esto / eso / aquello** — про неназванный предмет или ситуацию
целиком: **¿Qué es esto?**

## 9. Неопределённые

algo — что-то, nada — ничего, alguien — кто-то, nadie — никто, todo — всё,
todos — все, mucho — много, poco — мало, otro — другой.

- **No veo nada. Hay alguien. Todo está bien.**

## 10. Вопросительные

qué — что, quién — кто, cuál — какой, cuánto — сколько.

- **¿Qué haces? ¿Quién viene? ¿Cuánto cuesta?**

## 11. Относительные

que — который, quien — который (о людях), donde — где.

- **La chica que trabaja aquí. El hombre que habla español.**

## 12. Безличное se

- **Se vende.** — Продаётся.
- **Se habla español.** — Здесь говорят по-испански.
- **Se vive bien aquí.** — Здесь хорошо живётся.
